# IGS 고객센터 통합관리 시스템 — Portfolio Demo

가상의 고객센터 운영 환경을 재구성한 **웹 퍼블리셔 포트폴리오용 관리자 대시보드**입니다. IGS의 실제 내부 시스템이나 운영 데이터를 사용하지 않았습니다.

## 실행 방법

`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행하세요. 별도의 빌드, 서버, 라이브러리 설치는 필요하지 않습니다.

## 주요 기능

- 대시보드: KPI 카드, SVG 선형 차트, CSS 도넛 차트, 최근 상담 내역
- 상담 관리: 실시간 키워드 검색, 상태/유형 필터, 정렬, 페이지네이션
- 상담 상세: 팝업에서 처리 상태 변경 및 저장
- 신규 상담: 입력 폼으로 데모 상담 등록
- 고객 관리: 가상 고객 목록과 상담 내역 연결
- 상담원 관리: 상담원별 상태 및 처리 실적
- 통계 리포트: 월별 차트와 지표
- 환경 설정: 알림 설정, 데모 데이터 초기화
- 반응형 레이아웃: PC / 태블릿 / 모바일, 모바일 메뉴
- localStorage: 등록/상태 변경/설정 값 브라우저에 저장

## GitHub Pages 배포

1. GitHub에서 새 공개 저장소를 만듭니다 (예: `igs-admin-portfolio`).
2. 이 폴더 안의 `index.html`, `css`, `js` 폴더를 저장소 **최상위 경로**에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch 선택.
4. Branch `main`, 폴더 `/(root)`를 선택하고 Save를 누릅니다.
5. 잠시 뒤 `https://사용자명.github.io/igs-admin-portfolio/`에서 접속합니다.

## 기술 스택

HTML5 / CSS3 / Vanilla JavaScript / SVG / localStorage

## 포트폴리오 설명 시 유의점

이 화면은 기존 업무 경험을 토대로 새로 구현한 **개인 데모 프로젝트**입니다. 실무에서 실제로 개발한 IGS 내부 화면이라고 소개하지 마세요. 상단 KPI 및 통계는 시연용 가상 수치이며 상담 목록 일부 기능만 브라우저 저장소와 연동됩니다. 실제 서버 API나 데이터베이스 연동은 포함하지 않습니다.
